# Reel Picks

A React movie collection for saving favorite movies and shows, with title and
minimum-rating filters. Select a movie card to see its description and embedded
trailer.

## Run locally

```sh
npm install
npm run dev
```

Add a title, description, trailer embed URL, poster image URL, and rating out of
10 to save a pick.

## Deploy to GitHub Pages

The GitHub Actions workflow builds and deploys the app to
`https://bilaleb.github.io/forja/` on pushes to `main`. In the repository
settings, set **Pages → Build and deployment → Source** to **GitHub Actions**
to enable the first deployment.
